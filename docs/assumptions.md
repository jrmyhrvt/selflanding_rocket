# Assumptions & Limits

- Flat-Earth local frame; Earth rotation neglected.
- ISA troposphere only; T clamped if non-positive.
- Rigid body assumed later; flexibility neglected.
- Sensor models are phenomenological (noise/bias/drift/delay/dropout) – not calibrated to specific hardware.
- State estimate uncertainty is tracked conceptually; numeric covariance may be simplified.
- No real-time control interface; simulation-only.
