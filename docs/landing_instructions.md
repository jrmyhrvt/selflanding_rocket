# Landing-Visualisierung

Start:
```bash
cd selflanding_rocket
PYTHONPATH=. python3 landing_app.py
```

Bedienung: Target X/Y Slider ändern Zielposition, Start/Pause/Neustart.
Anzeige: t, h, v, dist(Ziel).
Hinweis: Nur echte Simulationsdaten, keine künstliche Trajektorie, Steuerung noch nicht implementiert (Ziellandungsgeschwindigkeit 0.5 m/s ist noch nicht erreicht).
